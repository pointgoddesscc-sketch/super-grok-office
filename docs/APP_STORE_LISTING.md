## Description
PSE Office OS is a self-contained macOS office operating system.

**Layer 0 — Key Forge**  
One master xAI key lives in the Secure Enclave. The OS mints eight scoped sub-keys for Chat, Imagine, Video, Brain, Docs, Projects, Inbox, and Calendar. Your team never sees the master. Revoke everything in one click.

**Layer 1 — Grok Brain**  
Chat and reasoning on grok-4 via /v1/responses. Images with grok-imagine-image. Video with grok-imagine-video + live polling. Same flows as the office-api-kit shell scripts.

**Layer 2 — Office Mesh**  
Nine modules share one OfficeStore: Chat Brain, Docs Forge, Project Pulse, Inbox Zero, Calendar Flow, Team Sync, Imagine Studio, Video Lab, Memory Vault.

**Layer 3 — Presence**  
Native MenuBar, Spotlight, Widgets, Shortcuts. Always within reach.

No API keys in git. No .env. Keys are born in the Key Forge UI and stored in Keychain only.
